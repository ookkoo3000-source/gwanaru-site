# 블로그 글 쓰는 법

이 폴더에 `.md` 파일을 하나 넣으면 글 한 개가 `/blog/파일이름/` 주소의 개별 페이지로 만들어집니다.
파일 이름은 영문·숫자·하이픈으로 (예: `2026-10-24-middle-math-first-exam.md`). 파일 이름이 곧 주소가 됩니다.

파일 맨 위에 아래 정보 블록을 붙이고, 그 아래에 본문을 씁니다.

```
---
title: 중2 수학 첫 시험, 과외로 준비하는 3주 계획
date: 2026-10-24
description: 중학교 2학년 첫 중간고사를 앞둔 학생이 과외로 3주 동안 무엇을 하면 좋은지 정리했습니다.
keywords: 중2 수학과외, 중학교 수학 과외, 중간고사 대비 과외
grade: middle          # elementary / middle / high / international (관련 글 묶기에 사용)
subject: math          # math / english / korean / science / social
---

본문은 여기에. 제목은 `##`, 목록은 `-`, 강조는 `**굵게**`.
```

- `title`과 `date`는 필수, 나머지는 있으면 좋습니다. `description`이 없으면 본문 앞 150자를 씁니다.
- 글 하나에 주제 하나, 제목에 핵심 키워드(학년+과목+상황)를 넣고, 본문은 600자 이상을 권합니다.
- 파일을 넣고 저장소에 올리면(push) 자동으로 빌드되어 사이트맵과 RSS에 추가됩니다.
