# edumegong.co.kr 과거 URL 조사와 처리안 (2026-10-24)

## 조사 방법과 한계
- **Wayback Machine CDX**로 `edumegong.co.kr/*` 중 200 응답 스냅샷 400건(HTML 371건)을 수집. 기간 2016~2025.
- **현재 서버 응답**: GitHub Pages 정적 사이트라 과외나루가 만든 페이지 외에는 모두 404.
- **확인하지 못한 것**: 구글·네이버 검색 결과에 남은 과거 제목(검색 도구에서 `site:` 결과를 받지 못함), 외부 사이트에서 과거 URL로 연결한 링크(백링크 도구·Search Console 미접근). → Search Console **링크 보고서**와 **색인 생성 > 페이지** 보고서에서 확인 필요.

## 과거 사이트의 성격
- 2016~2022: 공무원(계리직·경찰) 인강 판매 사이트 — `/course-category/`, `/course/`, `/상품/`, `/lesson/`, `/dt_teachers/`(강사), `/eg-login/`, `/forums/`, `/계리직-시험안내/`, `/경찰공무원시험/` 등 (워드프레스 LMS 형태).
- 2019~2024: `/1vs1/` 게시판(질문·답변형, 112건).
- 2024~2025: 과외·공무원과 무관한 글(건물 청소 업체, 한자 기출문제, 우정9급 시험일정) — 도메인이 만료 후 재사용되었거나 방치된 시기의 글로 보임.
- 어느 것도 현재 서비스(초·중·고 과외 상담)와 같은 목적의 콘텐츠가 아님.

### 결정 근거
- 과거 콘텐츠 중 **현재 서비스와 같은 목적의 페이지가 없으므로 301 대상이 없음.** 관련 없는 강의·상품·로그인 페이지를 과외 메인으로 몰아 보내지 않음(지시사항 3).
- GitHub Pages는 410을 낼 수 없어 404로 통일. 대신 **404 페이지에 "이 주소는 현재 과외나루로 운영되며 이전 사이트 페이지는 제공하지 않는다"는 안내와 주요 링크**를 넣어, 옛 검색 결과로 들어온 방문자가 바로 떠나지 않게 함(`noindex`).
- 외부 링크 조사 결과 **특정 과거 URL로 의미 있는 유입이 확인되면** 그때 해당 URL만 개별 검토(관련 콘텐츠가 있으면 301, 없으면 404 유지).

## 사용자가 확인할 것
1. Search Console → **링크** 보고서: 과거 URL로 들어오는 외부 링크 상위 목록. 유입이 있는 URL이 있으면 알려주세요.
2. Search Console → **색인 생성 > 페이지**: "찾을 수 없음(404)"에 과거 URL이 많이 보이는 것은 정상(시간이 지나면 색인에서 빠짐). 삭제 요청은 하지 않아도 됩니다.
3. 네이버 서치어드바이저 → **리포트 > 사이트 진단 / 검색 노출**: 과거 제목이 보이면 메인 URL 수집 요청 1회.
